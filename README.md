# 🇮🇳 India Data Explorer

An interactive geographic data visualization project built with Python, Pandas, Plotly, and Streamlit.

India Data Explorer allows users to explore district-level data across India using an interactive map. Users can select a state and choose different parameters to control the size and color of the visualized data points.

## 🚀 Features

- 🗺️ Interactive map of India
- 📍 District-level geographic visualization
- 🔎 Filter data by state
- 📊 Select a primary parameter to control marker size
- 🎨 Select a secondary parameter to control marker color
- 🌐 Explore the complete dataset or an individual state
- 🖱️ Interactive Plotly map with district information on hover
- 🎛️ Simple Streamlit interface

## 🛠️ Technologies Used

- **Python**
- **Pandas** – data loading and filtering
- **NumPy** – numerical computing
- **Streamlit** – interactive web application
- **Plotly Express** – interactive geographic visualization
